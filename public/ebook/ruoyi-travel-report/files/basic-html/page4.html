山西农业大学软件工程专业实训软件开发设计文档

1.1.3 运行环境
      后端运行于 Windows 或 Linux 系统，需要 JDK 1.8、MySQL 5.7、Redis、Maven、

Spring Boot 2.x 和若依框架 3.x。前端后台运行于 Node.js 环境，使用 Vue 2.x、
Element UI 和 Axios。小程序端使用微信开发者工具和微信小程序基础库。开发工具包
括 IntelliJ IDEA 或 Eclipse、VS Code、Navicat。云服务方面，系统依赖百度 AI 图
像搜索，文件存储可选阿里云 OSS、华为云 OBS 或本地文件存储。
1.1.4 设计和实现上的限制

      本系统必须遵循若依框架的分层规范，即 Controller 层、Service 层、Mapper 层和
数据库层。接口路径、请求方法、参数名和返回结构必须与前端约定一致，例如
/travel/backstage/search、/travelVideo/list、/activ/list 等。主键统一使用雪花 ID，
由后端 IdWorker 生成，除 travel_vr 表自增外，其余表均不使用数据库自增。分页使
用 PageHelper ， 列 表 接 口 返 回 TableDataInfo ， 单 对 象 返 回 AjaxResult 或
CommonResult。文件上传需要兼容本地存储和云存储，识别库入库需要调用百度 AI 接口。
小程序端 token 鉴权使用 Authorization 头，后台管理端使用 Bearer 前缀。

1.2 外部接口需求

1.2.1 用户界面
      后台管理端：基于 Vue + Element UI，左侧菜单导航，右侧内容区。景点管理页包含

搜索栏、表格、分页、新增/编辑弹窗、图片上传组件。识别库管理页以图片墙形式展示，
支持上传、删除。轮播图、封面图、VR、历史人物、视频、活动等页面均为标准表格 + 弹
窗表单。

      小程序端：首页展示轮播图、活动入口、景点推荐；景点列表页支持分类 tab、附近、
搜索；景点详情页展示图片、富文本介绍、音频、VR 入口、历史人物、相关景点；拍照识
别页调用相机上传图片，展示识别结果或推荐列表；视频页展示视频列表和播放详情；历
史人物页展示人物信息。
1.2.2 硬件接口

      无特殊硬件接口，仅依赖服务器、数据库服务器、网络设备。小程序端使用手机摄像
头拍照上传。
1.2.3 软件接口

      百度 AI 图像搜索：用于识别库入库（similarAdd/similarAddUrl）和拍照识别
（similarSearch）、删除（similarDeleteBySign）。

      微信小程序登录：调用微信 jscode2session 接口获取 openid、sessionKey。
      微信手机号解密：调用微信 getPhoneNumber 接口解密手机号。
      文件上传：本地存储使用 RuoYiConfig.getUploadPath()，云存储可选阿里云 OSS、
华为云 OBS。
      数据库：MySQL 5.7，通过 MyBatis / tk.mybatis 访问。
