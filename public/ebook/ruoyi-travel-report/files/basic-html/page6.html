山西农业大学软件工程专业实训软件开发设计文档

1.4 其它非功能需求

1.4.1 性能需求
      列表接口响应时间 < 500ms（数据量 1 万条以内）。
      分页查询使用 PageHelper，避免全表扫描。
      景点详情聚合查询使用主表 + 详情表 + 分类表，避免 N+1 查询（批量回填分类名）。
      拍照识别调用百度 AI 接口，设置超时时间（连接 2s，Socket 30s），并使用

RateLimiter 限流（0.7 QPS）。
      文件上传限制图片 2M，支持 gif/jpg/jpeg/png；音频支持 mp3/wav。
      附近景点使用 Haversine 公式在内存中计算距离并排序，支持分页。

1.4.2 安全措施需求
      后台管理端接口使用 @PreAuthorize 进行权限校验（部分接口已加，部分待补）。
      小程序端使用 token 鉴权，token 存于 Redis，有效期可配置。
      敏感操作（删除、修改）需登录后执行。
      文件上传限制类型和大小，防止恶意上传。
      百度 AI 密钥、数据库密码等敏感信息配置在 application.yml 或 sys_config 表

中，不硬编码。
1.4.3 安全性需求

      防止 SQL 注入：使用 MyBatis 预编译参数。
      防止 XSS：富文本内容前端渲染时过滤，后端存储原样。
      防止越权：小程序端只能访问已发布（status=1）的景点、活动、视频等。
      数据备份：定期备份 MySQL 数据库。
1.4.4 软件质量属性
      易用性：后台管理界面简洁，操作流程清晰；小程序端适配移动端，交互流畅。
      可移植性：后端基于 Spring Boot，可部署于 Windows/Linux；前端基于 Vue，可打
包为静态资源；小程序端可发布至微信平台。
      可维护性：分层清晰，Controller 只做参数校验和返回，Service 处理业务，Mapper
负责 SQL；使用 DTO/VO 隔离实体。
      可扩展性：新增业务模块只需增加 Controller、Service、Mapper、实体和表。
      安全性：鉴权、权限、参数校验、文件上传限制。
1.4.5 业务规则
      景点、活动、视频等数据只有 status=1（或 deleted=0）时才在小程序端展示。
      景点分类通过 travel_joint 表关联，一个景点可属于多个二级分类。
      识别库入库需先上传图片，再调用百度 AI 接口，成功后记录 cont_sign。
      拍照识别时，若相似度分数低于阈值（60），则返回推荐景点列表。
      浏览量埋点记录用户 ID、景点 ID、事件类型、来源等。
